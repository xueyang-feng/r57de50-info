R57DE50 PRODUCTION

Privacy policy

This policy describes Google user data handled by r57de50 Production, a personal application operated by Xueyang Feng. Effective October 16, 2026.

Data accessed and purpose

Google Drive authorization allows the application, through rclone, to access file contents and metadata such as names, folder locations, modification times, and file identifiers within the permissions granted by the operator. The configured workflow uses trading audit records, historical backtest inputs, system-status logs, and account snapshots for archival, monitoring, reconciliation, and private performance analysis.

The current Drive permission may allow reading, creating, updating, or deleting Drive files beyond the folders used by the configured workflow. This permission is not limited merely by the folder names described on the homepage. The operator controls the configuration and authorization.

Storage and processing

Records are stored in the operator’s Google Drive and Google Cloud environment, including a virtual machine, local archives and backups, and Cloud Storage used by private dashboards. OAuth credentials and tokens are held in the operator’s rclone configuration. They are not included on these public information pages.

Sharing and use limitations

Google and the hosting providers process data as needed to provide the configured storage, hosting, and authorization services. The operator may provide selected records to analysis services when explicitly authorized. Google user data is not sold or used for advertising. This workflow does not use Google user data to train generalized AI or machine-learning models. Google user data is not intentionally published through these information pages.

Retention and deletion

Archives are retained until the operator deletes them. Deleting a source file does not automatically remove its copies from local archives, cloud storage, backups, or previously generated analytics. To request deletion, contact the operator at xueyang.feng@gmail.com. The operator must remove the applicable copies and rebuild affected analytics where necessary.

Revoking access

The Google account owner can revoke this application’s access through Google Account connections. Revocation stops future authorized Drive access after applicable tokens cease working; it does not itself delete previously archived files.

Visitors to these pages

These static pages contain no analytics scripts, advertising, forms, or trading data. GitHub Pages, when used to host them, may process technical request information under GitHub’s privacy statement.

Contact and changes

Questions or data requests: xueyang.feng@gmail.com. Changes will be reflected on this page with an updated effective date.
